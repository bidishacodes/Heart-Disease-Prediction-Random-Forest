# Heart Disease Prediction Using Random Forest

## Project Overview

This project uses a Random Forest Classification algorithm to predict the presence of heart disease based on patient health attributes.

## Dataset

* Dataset: Heart Failure Prediction
* Source: Kaggle
* Records: 918
* Target variable: HeartDisease

[Download Dataset](https://www.kaggle.com/datasets/fedesoriano/heart-failure-prediction)

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Google Colab

## Project Workflow

1. Dataset loading
2. Exploratory Data Analysis
3. Data preprocessing
4. Handling missing values
5. Categorical encoding
6. Train-test splitting
7. Random Forest model training
8. Model evaluation
9. Feature importance analysis

## Model Performance

| Metric    |  Score |
| --------- | -----: |
| Accuracy  | 87.50% |
| Precision | 88.35% |
| Recall    | 89.22% |
| F1 Score  | 88.78% |

The Random Forest classifier achieved 87.50% accuracy on the test dataset. This project demonstrates the application of machine learning for healthcare-related data analysis.
